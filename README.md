## 🚀 Overview

**simple-calculator** is a lightweight command-line application that allows users to execute basic arithmetic operations and square roots through a clean terminal menu[cite: 1].

---

## ✨ Features

* **➕ Addition**: Calculates the sum of two numbers[cite: 1].
* **➖ Absolute Subtraction**: Returns the absolute difference between two numbers[cite: 1].
* **✖️ Multiplication**: Multiplies two numbers[cite: 1].
* **➗ Detailed Division**: Calculates and displays quotient and remainder[cite: 1].
* **√ Square Root**: Computes exact square root using Python's native `math` module[cite: 1].
* **🛡️ Input Validation**: Built-in protection against non-numeric inputs and division by zero.
