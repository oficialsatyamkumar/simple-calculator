# Simple Calculator

A interactive command-line interface (CLI) calculator built using Python. This application allows users to perform standard mathematical operations in a loop until they choose to exit.

---

## Features

* **Addition**: Calculates the sum of two numbers.
* **Subtraction**: Returns the positive difference between two numbers.
* **Multiplication**: Calculates the product of two numbers.
* **Division**: Displays both quotient and remainder for two given numbers.
* **Square Root**: Calculates the square root of a given number using Python's built-in `math` module.
